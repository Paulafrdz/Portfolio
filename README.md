# Portfolio - Paula Fernandez Aranda

Personal portfolio website showcasing my projects and skills as a Full Stack Web Developer.

## 🚀 Features

- **Animated Text Reveal** - Progressive text reveal on scroll
- **Expanding Letter Transition** - Dramatic section transition with scaling letter "P"
- **Project Showcase** - Featured projects with detailed case studies
- **Responsive Design** - Optimized for desktop and mobile devices
- **Modern UI/UX** - Clean, functional interface with attention to detail

## 🛠️ Built With

- **React** - UI library
- **Framer Motion** - Animations and scroll effects
- **CSS3** - Styling and layouts
- **Vite** - Build tool and dev server
